Files

- Burger.java — Represents individual burgers, including their names, prices, and calories.
  
- BurgerShop.java — Handles menu information, account balances, order processing, and order history.
  
- BurgerShopFE_GUI.java — Implements the graphical user interface and connects user interactions to the application back end.


How to Run

- Download all three Java files and place them in the same folder.
- 
- Open a terminal in the project folder.
- 
- Compile the program:javac Burger.java BurgerShop.java BurgerShopFE_GUI.java
- 
- Run the application: java BurgerShopFE_GUI
- 
- Use the graphical interface to select burgers, add funds, place orders, and view account information.
